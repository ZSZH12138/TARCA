# Stage1B v2 Freeze Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to
> implement this plan task-by-task. TARCA forbids subagents, so execution is inline in the
> current primary task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze the confirmed Stage1B target as the single active `v2`, publish a detailed
authority handoff snapshot, remove obsolete local intermediates, simplify measured code hotspots,
fast-forward local `main`, and push only approved small artifacts and source files to GitHub.

**Architecture:** Replace numbered Stage1B revisions with one hash-addressed `v2` freeze directory
and an active pointer. Preserve full heavyweight evidence as one verified local archive while Git
tracks only canonical JSON/SHA-256 evidence. Reduce code size by extracting stable internal modules
behind existing public import surfaces, then validate the merged `main` before a non-force push.

**Tech Stack:** Python 3.11, Pydantic, PyTorch, SQLite, FastAPI, React/TypeScript, pytest, Ruff,
Mypy, Vitest, Playwright, Git.

**Spec:** `docs/superpowers/specs/2026-08-29-stage1b-v2-freeze-closeout-design.md`

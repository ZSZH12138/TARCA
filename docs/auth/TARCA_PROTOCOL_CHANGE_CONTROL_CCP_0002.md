## 1. 触发原因

Stage1B v2 首次完整资格运行完成 74/74 个任务，但总门禁失败。结果显示：

- `lorenz96_f10_v2` 不具备跨全部时距的稳定神经优势；
- `lorenz96_twoscale_v2 + ITransformerReference` 的总体 CRPS 胜率为 98.6111%，总体 CRPS skill 为 +4.067%；
- 双尺度世界 h1–6 为 72/72 胜、CRPS skill +13.2423%；h7–12 为 64/72 胜、CRPS skill +2.0937%；h13–24 为 19/72 胜、CRPS skill -1.0055%；
- 原相对校准护栏要求神经模型的校准误差接近或优于 VAR，因此即使短期预测有效，仍使世界失败。

上述结果是在观察后确定研究焦点的探索性筛选证据，不能直接充当确认性结论，也不得删除或伪装成未发生。

## 2. 已批准的确认范围

在同一 v2 科学系列内建立 `v2-r2` 确认候选，不创建 v3：

- 世界仅为 `lorenz96_twoscale_v2`；
- 神经预测器仅为官方 iTransformer 适配器；
- 基线为既有调优 VAR；
- h1–6 是唯一主要判断时距；
- h7–12 作为次要描述；
- h13–24 作为预先声明的能力边界；
- PatchTST 和单尺度世界保留在 pilot 证据中，但不参与本轮确认门禁。

此范围服务于后续机制解释：只解释已经确认具备预测效用的“世界—模型—时距”组合，不宣称模型在所有世界、指标或时距上都优于 VAR。

## 3. 盲确认种子与隔离

新确认根种子固定为：


生成规则为：对 `TARCA|Stage1B|v2-r2|confirmation|i`（`i=1..3`）取 SHA-256，读取前 8 字节大端整数并对 `2**31-1` 取模。

新种子与首次资格种子及 E01/E02 正式保留种子均不重叠。首次资格模型、预测和评分不得计入确认；必须重新生成资格轨迹、重新训练并重新预测。E01/E02 继续不运行，正式保留种子继续封存。

## 4. 确认门禁

主要指标仍为 h1–6 的 CRPS。既有以下要求继续适用：至少 40 个完整轨迹比较单元、胜率至少 65%、CRPS skill 严格大于 0、三个确认种子覆盖、已见与未见状态均为多数胜出、paired bootstrap 不支持整体稳定劣于 VAR、NLL/MAE/最坏状态不超过既有相对容差、概率尺度有效、内部位置可操作。

校准护栏改为模型自身的绝对可靠性要求：名义 90% 区间的平均绝对覆盖误差不得超过 0.05。它不再要求神经模型的校准误差相对 VAR 更好。所有时距的 CRPS、NLL、MAE、coverage 和校准行仍完整保存；次要与边界时距不能改变 h1–6 的主要门禁结果。

## 5. 运行、防窥视和监督

- 配置、种子、代码和来源在运行前哈希；
- 新确认使用独立 artifact root，不覆盖首次资格运行；
- 调度器按每次服务器的实际资源探针分配任务，不固定硬件型号或数量；
- 训练周期性写原子检查点，断电后只允许明确的手动 `resume`；
- 运行进程不依赖 Codex 或 SSH 会话存活；
- 用户通过只读前端查看进程、任务、CPU、内存、GPU、显存、检查点和 ETA；
- 运行中前端不显示 CRPS、胜率或中间科学结论，避免据中间结果调整方案。

## 6. 结果与冻结

首次完整资格运行作为 pilot 失败证据永久保留，但不是活动冻结版本。确认运行通过后，才可在用户审阅后冻结 `v2-r2`；冻结对象包含世界、模型、VAR、主要时距、配置/代码/来源哈希、三个确认种子和完整结果。正常情况下冻结不可修改，用户可通过后续明确授权和新的 CCP 修改或覆盖。

若确认失败，保存失败原因和全部证据，不建立新的活动冻结版本；不得用重复试跑直到通过来替代新的变更控制。
